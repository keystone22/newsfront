How the trial was drawn

{{ headlines }} headlines from {{ newsrooms|join(', ') }} were matched by shared words. A story qualifies for {{ name }} when {{ name }}'s own feeds carry it and at least {{ min_newsrooms }} different newsrooms are running it; {{ qualifying|length }} did. The count is a gate, not a score: among qualifying stories the draw is random, and a story on six newsrooms is no likelier to be picked than one on two. The random slots come from the ordinary pool of {{ pool }} {{ name }} candidates.

Most big stories qualify for more than one section, so each is drawn for one trial page only, and two versions of the same event are never both drawn. Sections are dealt narrowest first — {{ order|join(' → ') }} — only so the smaller ones can fill; each still draws at random from what is left.

AP counts as a newsroom but is not in any live draw. Its copy can appear only for a story this section's own feeds are also carrying.
