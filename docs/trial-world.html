How the trial was drawn

993 headlines from AP, Al Jazeera, BBC, DW, Euronews, France 24, Guardian, Le Monde, NPR, NYT, Politico, Reuters were matched by shared words. A story qualifies for World when World's own feeds carry it and at least 2 different newsrooms are running it; 66 did. The count is a gate, not a score: among qualifying stories the draw is random, and a story on six newsrooms is no likelier to be picked than one on two. The random slots come from the ordinary pool of 431 World candidates.

Most big stories qualify for more than one section, so each is drawn for one trial page only, and two versions of the same event are never both drawn. Sections are dealt narrowest first — Europe → Top News → World — only so the smaller ones can fill; each still draws at random from what is left.

AP counts as a newsroom but is not in any live draw. Its copy can appear only for a story this section's own feeds are also carrying.
